You are given a string s consisting of lowercase English letters.

In one operation, 
you can select any substring of s that is not the entire string 
and sort it in non-descending alphabetical order.

Return the minimum number of operations 
required to make s sorted in non-descending order. 
If it is not possible, return -1.


sorted string (a -> z)

先找 String 當中最大與最小，理論上他們要在頭跟尾(0, n-1)

如果沒有 -> sorted operation

切成 substring 後再進行排序
    - substring 不能是整個 String


case 1

"ardc" -> 1 (恰好一個最小與最大其中一個就在頭或尾) 

sort rdc -> "acdr"

只要對其他進行排序就是 sorted string

case 2

"rdca" -> 3 (最大和最小剛好對調)

op1 -> "rdc"先排序 -> "cdra"

op2 -> "ra" 先排序 -> "cdar"

op3 -> "cda" 排序 -> "acdr"
